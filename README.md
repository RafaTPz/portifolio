<h1 align="center">Portfólio — Rafael Tadeu Praça</h1>

<p align="center">
  Portfólio pessoal convertido de HTML/CSS/JS puro para <strong>React + Vite</strong>,
  com React Router, tema claro/escuro e design responsivo.
</p>

## 💻 Tecnologias

- [React 19](https://react.dev/)
- [Vite](https://vite.dev/)
- [React Router](https://reactrouter.com/)
- CSS puro com variáveis (design tokens) e suporte a tema claro/escuro

## 📄 Páginas

| Rota          | Conteúdo                                            |
| ------------- | --------------------------------------------------- |
| `/`           | Home com apresentação, typewriter e tecnologias     |
| `/curriculum` | Currículo: experiência, formação, competências      |
| `/sobre-mim`  | Sobre mim e perfil profissional                     |
| `/motivacao`  | Minha trajetória e motivação                        |
| `/trabalhos`  | Projetos acadêmicos e pessoais                      |
| `/contato`    | Canais de contato                                   |

## ✨ Funcionalidades

- Tema claro/escuro com persistência em `localStorage` e respeito a `prefers-color-scheme`
- Efeito typewriter na Home
- Animações de reveal ao rolar (com suporte a `prefers-reduced-motion`)
- Navegação SPA com rota ativa destacada e menu mobile
- Layout totalmente responsivo

## 🚀 Rodando o projeto

```bash
# instalar dependências
npm install

# ambiente de desenvolvimento
npm run dev

# build de produção
npm run build

# visualizar build de produção
npm run preview
```
